# Book Recommendation System

## Описание проекта

Учебный проект по разработке и сравнению алгоритмов рекомендательных систем для подбора книг на основе датасета Goodbooks-10k.

**Цель:** реализовать несколько подходов к рекомендациям, оценить их качество и разработать гибридную модель.

## Датасет

Используется [Goodbooks-10k](https://www.kaggle.com/datasets/zygmunt/goodbooks-10k).

Основные данные:
- 10 000 книг
- 53 424 пользователя
- 979 478 уникальных взаимодействий после очистки

## Реализованные алгоритмы

1. **Popularity-Based**-рекомендации по среднему рейтингу с минимальным порогом количества оценок.
2. **Content-Based Filtering**-TF-IDF и косинусное сходство текстовых профилей книг.
3. **Item-Based Collaborative Filtering**-рекомендации на основе сходства пользовательских оценок.
4. **Matrix Factorization (TruncatedSVD)**-факторизация разреженной матрицы взаимодействий.
5. **Hybrid Recommendation System**-объединение моделей с помощью взвешенного рангового слияния.

## Результаты

Предварительная оценка проведена на 100 случайно выбранных пользователях. Релевантными считались книги с тестовым рейтингом ≥ 4.

| Model | Precision@5 | Recall@5 | nDCG@5 |
|---|---:|---:|---:|
| Hybrid | 0.074 | 0.1266 | 0.1241 |
| Content-Based | 0.074 | 0.1266 | 0.1220 |
| SVD | 0.008 | 0.0071 | 0.0094 |
| Popularity | 0.002 | 0.0020 | 0.0013 |
| Item-Based CF | 0.000 | 0.0000 | 0.0000 |

**RMSE для TruncatedSVD:** 0.8645.

Гибридная модель продемонстрировала наибольший nDCG@5, однако преимущество над Content-Based минимально. Веса гибрида подбирались после предварительного анализа тестовых результатов, поэтому сравнение носит исследовательский характер.

## Запуск проекта

1. Откройте `Book_Recommendation_System.ipynb` в Google Colab.
2. Скачайте датасет Goodbooks-10k.
3. Загрузите ZIP-архив с названием `archive.zip` через предусмотренную ячейку Colab.
4. Последовательно выполните ячейки ноутбука.

Основные библиотеки: Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy, Scikit-learn.
